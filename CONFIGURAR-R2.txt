CONFIGURAR O R2 — PASSO A PASSO

Painel: https://dash.cloudflare.com  >  R2


1) CRIAR DOIS BUCKETS

   aura-publico    imagens (joia, catalogo, banner, logo)
   aura-privado    comprovante, foto clinica, PDF de termo

   No aura-privado NAO habilite acesso publico. Deixe fechado.
   (nome é livre; se mudar, me avise qual usou)


2) DOMINIO NO BUCKET PUBLICO

   aura-publico > Settings > Custom Domain
   Ex.: cdn.monitence.com   (o dominio precisa estar nesta conta Cloudflare)

   IMPORTANTE: decida com calma. Esse endereco fica gravado dentro das
   URLs no banco na migracao. Trocar depois exige refazer tudo.


3) CRIAR CHAVE S3 NOVA

   R2 > Manage API Tokens > Create API Token
   Permissao:  Object Read & Write
   Buckets:    marque OS DOIS

   A atual nao serve (é escopada, da erro 403).
   O Secret aparece UMA vez. Copie na hora.


4) ME MANDAR

   R2_BUCKET_PUBLIC     =
   R2_BUCKET_PRIVATE    =
   R2_PUBLIC_BASE_URL   = https://...
   R2_ACCESS_KEY_ID     =
   R2_SECRET_ACCESS_KEY =

   O R2_ENDPOINT eu ja tenho.

     Voce nao cria nada disso a mao.

     faltando, a API se recusa a subir. É proposital — meia configuracao
     grava arquivo que ninguem consegue ler depois.
